## 3. CHRONOLOGICAL STEP-BY-STEP IMPLEMENTATION PLAN
----------------------------------------------------------------------------

### STEP 1: Install Pure-JS BM25 Dependencies
  Target Directory: `backend/`
  Packages to Install:
    - `wink-bm25-text-search`: Pure JavaScript BM25 engine.
    - `wink-nlp`: Tokenization pipeline required by wink-bm25.
    - `wink-eng-lite-web-model`: English language model for wink-nlp.

  Command:
    cd backend && npm install wink-bm25-text-search wink-nlp wink-eng-lite-web-model

  Safety Note: Pure JS packages ensure compatibility across environments without native C++ compilation dependencies.


### STEP 2: Add `deleteNoteChunks` to Qdrant Service
  File: `backend/services/ai/qdrant_service.js`

  Action: Export a new function `deleteNoteChunks(noteId)`:
    async function deleteNoteChunks(noteId) {
        await qdrantClient.delete(COLLECTION_NAME, {
            filter: {
                must: [{ key: "noteId", match: { value: noteId } }]
            }
        });
    }

  Safety Note: Wraps Qdrant payload filter deletion to clean vector chunks when a note is deleted.


### STEP 3: Create `bm25_service.js` (In-Memory Scoped BM25 Index Manager)
  File: `backend/services/ai/bm25_service.js` (NEW FILE)

  Exported Functions:
    1. `indexChunks(chunks, { noteId, userId })`
       - Creates or retrieves the user's BM25 index (stored in a `Map<userId, engine>`).
       - Adds each chunk with metadata: `{ fusionKey: `${noteId}-${chunkIndex}`, noteId, userId, chunkIndex, pageNumber, text }`.
       - Calls `engine.consolidate()`.

    2. `removeNoteFromIndex(userId, noteId)`
       - Rebuilds the user's BM25 index excluding documents matching `noteId`.
       - Deletes user entry from `Map` if zero documents remain.

    3. `bm25Search(query, { userId, noteId, limit = 10 })`
       - Returns `[]` immediately if no index exists for `userId` (graceful fallback).
       - Runs BM25 search over the user's documents.
       - Filters results by `noteId` if specified (ensuring document-specific RAG support).
       - Returns formatted candidates:
         `[{ fusionKey, score, payload: { text, noteId, userId, chunkIndex, pageNumber } }]`.

    4. `rebuildAllIndexes(notes)`
       - Called during server boot.
       - Accepts array of notes from MongoDB: `[{ _id, uploadedBy, extractedText }]`.
       - Uses helper to parse `[[PAGE:N]]` markers and chunk text identically to `ingestion_service.js`.
       - Populates in-memory BM25 index for all users.

  Safety Note: User isolation is strictly enforced because each `userId` key maps to an isolated BM25 instance.


### STEP 4: Create `rrf_service.js` (Reciprocal Rank Fusion)
  File: `backend/services/ai/rrf_service.js` (NEW FILE)

  Exported Function:
    `reciprocalRankFusion(denseResults, bm25Results, { k = 60, topN = 5 })`

  Algorithm:
    1. Initialize `Map<fusionKey, { rrfScore, payload }>` accumulator.
    2. Dense Results Iteration:
       - `fusionKey = `${item.payload.noteId}-${item.payload.chunkIndex}``
       - `rrfScore += 1 / (k + rank)`
    3. BM25 Results Iteration:
       - `fusionKey = item.fusionKey`
       - `rrfScore += 1 / (k + rank)`  (Deduplicates automatically if chunk is present in both search lists).
    4. Sort accumulator entries by `rrfScore` descending.
    5. Slice top `topN` entries and return:
       `[{ fusionKey, rrfScore, payload: { text, noteId, userId, chunkIndex, pageNumber } }]`.

  Safety Note: Payload format matches Qdrant structure expected by `buildRagPrompt`.


### STEP 5: Add Non-Blocking BM25 Warm-Up on Server Boot
  File: `backend/src/server.js`

  Action:
    In the DB connection completion block:
    ```javascript
    const Note = require('./models/note');
    const { rebuildAllIndexes } = require('../services/ai/bm25_service');

    try {
        const allNotes = await Note.find({}, '_id uploadedBy extractedText');
        await rebuildAllIndexes(allNotes);
        console.log(`[BM25] Warm-up complete for ${allNotes.length} notes.`);
    } catch (err) {
        console.warn('[BM25] Warm-up warning:', err.message);
    }
    ```

  Safety Note: Wrapped in `try/catch` so warm-up errors never crash server startup.

### STEP 7: Add Qdrant & BM25 Cleanup to Note Deletion
  File: `backend/src/controllers/noteController.js`

  Action:
    In `deleteNote`, right after `await note.deleteOne()`:
    ```javascript
    // Clean up Qdrant vector chunks
    try {
        const { deleteNoteChunks } = require('../../services/ai/qdrant_service');
        await deleteNoteChunks(note._id.toString());
    } catch (qdrantErr) {
        console.warn('[Qdrant] Chunk deletion cleanup skipped:', qdrantErr.message);
    }

    // Clean up BM25 index chunks
    try {
        const { removeNoteFromIndex } = require('../../services/ai/bm25_service');
        await removeNoteFromIndex(req.user._id.toString(), note._id.toString());
    } catch (bm25Err) {
        console.warn('[BM25] Index removal cleanup skipped:', bm25Err.message);
    }
    ```

  Safety Note: Isolated in individual try/catches; deletion failures in vector/bm25 storage will log warnings without blocking HTTP response.


### STEP 8: Upgrade `chatWithPdf` to Hybrid Retrieval
  File: `backend/services/ai/chat_services.js`

  Action:
    Replace single `retrieveChunks` call with hybrid dense + BM25 + RRF execution:
    ```javascript
    const DENSE_LIMIT = 10;
    const BM25_LIMIT  = 10;
    const FINAL_LIMIT = 5;

    // 1. Dense retrieval
    const denseChunks = await retrieveChunks(message, { userId, noteId, limit: DENSE_LIMIT });

    // 2. BM25 keyword retrieval with safe fallback
    let bm25Chunks = [];
    try {
        const { bm25Search } = require('./bm25_service');
        bm25Chunks = await bm25Search(message, {
            userId: userId.toString(),
            noteId: noteId ? noteId.toString() : null,
            limit: BM25_LIMIT
        });
    } catch (bm25Err) {
        console.warn('[BM25] Search skipped, falling back to dense:', bm25Err.message);
    }

    // 3. RRF Fusion
    const { reciprocalRankFusion } = require('./rrf_service');
    const chunks = reciprocalRankFusion(denseChunks, bm25Chunks, { topN: FINAL_LIMIT });
    ```

    In return value sources mapping:
    `score: chunk.rrfScore ?? chunk.score`

  Safety Note: Ensures backward compatibility. If BM25 encounters an issue, `denseChunks` seamlessly feeds the LLM prompt.
